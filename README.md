# 🏛️ HTML5 Form Elements – Architectural Firm Consultation Form

## 📌 Experiment 2

### Aim
To design and implement an interactive HTML5 web form using various HTML5 form elements and validation features for an **Architectural Firm Website**.

---

## 📖 Description

This project is a continuation of the **Karunya Architectural Firm** website developed in Experiment 1. In this experiment, an interactive **Consultation Booking Form** is created using HTML5 form elements. The form allows clients to enter their project details and request architectural consultation.

The project demonstrates the use of different HTML5 input controls along with built-in browser validation features.

---

## ✨ Features

- Client Name input
- Email Address validation
- Password field
- Mobile Number validation
- Project Budget input
- Project Start Date picker
- Project Type (Radio Buttons)
- Required Services (Checkboxes)
- Architect Selection (Dropdown List)
- Project Address (Textarea)
- Preferred Exterior Color Picker
- Building Plan File Upload
- Project Priority Slider
- Submit and Reset buttons
- HTML5 Form Validation

---

## 🛠️ Technologies Used

- HTML5

## 📸 Output

The webpage displays a clean **Architectural Firm Consultation Form** where users can enter project information and submit their consultation request using various HTML5 form controls.
